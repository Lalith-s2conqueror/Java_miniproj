# Campus Complaint Portal System

A Java-based web application designed to simplify campus complaint management by providing a centralized platform for students to submit complaints, track their status, and communicate with administrators regarding campus-related issues.

## 📌 Project Overview

The Campus Complaint Portal System aims to replace traditional, manual complaint-handling processes with an organized and transparent digital solution. Students can report issues related to campus infrastructure, sanitation, academics, IT facilities, and other services. Administrators can review complaints, update their status, and record remarks until the issues are resolved.

This project is developed as a **Java Mini Project for Second-Year Engineering** to demonstrate practical implementation of Java programming, web development, database connectivity, and collaborative software development.

## 🎯 Objectives

* Provide a centralized platform for submitting campus complaints.
* Enable students to track complaint progress.
* Allow administrators to manage and resolve complaints efficiently.
* Maintain complaint records in a structured database.
* Improve transparency and accountability in campus complaint management.
* Apply software development practices using Java, MySQL, and GitHub.

## ✨ Planned Features

### Student Module

* Student registration and login.
* Student dashboard.
* Submit complaints with a title, category, description, and location.
* Receive a unique complaint ID.
* View submitted complaints and their current status.
* Access administrative remarks.

### Administrator Module

* Secure administrator login.
* View and manage submitted complaints.
* Search and filter complaints by category or status.
* Update complaint status.
* Add administrative remarks and resolution details.

### Complaint Tracking

Complaints will follow a defined workflow:

`Submitted → Under Review → In Progress → Resolved`

Complaints may also be rejected with an appropriate reason.

## 🏗️ Project Architecture

The application will follow a layered architecture:

* **Presentation Layer:** JSP, HTML, CSS, and JavaScript.
* **Controller Layer:** Java Servlets for processing requests.
* **Data Access Layer:** JDBC and DAO classes for database operations.
* **Database Layer:** MySQL for storing users and complaints.

## 👥 Team Collaboration

The project will be developed collaboratively using GitHub, with each team member responsible for a specific module.

* **Member 1:** Frontend and User Interface.
* **Member 2:** Authentication and Common Backend Logic.
* **Member 3:** Database and Complaint Management.
* **Member 4:** Administrator Dashboard and Integration Testing.

Team members will use separate Git branches and pull requests to manage code changes and integrate their work.
